# Учебный центр ТИК

Публичная статическая версия внутреннего учебного сайта для менеджеров ТИК.

- 12 товарных категорий;
- шесть методичек по продукту и монтажным границам;
- учебное видео по заливке стыка в ППУ-изоляции;
- собственные учебные изображения и ссылки на источники.

Материалы помогают квалифицировать запрос, но не заменяют проект, паспорт
изделия, технологическую карту или инженерный подбор.

Сайт опубликован через GitHub Pages без поисковой индексации. Репозиторий и
сайт остаются публичными для любого человека, у которого есть ссылка.
